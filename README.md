# X Cleaner 🧹

一个在本机终端运行的 X 账号清理工具。它通过当前登录会话扫描账号内容，让用户先查看分类和数量，再自行选择要清理的项目。

> 非 X 官方工具，仅用于管理你自己的账号。X 的网页内部接口会变化，因此任何扫描结果都应以程序显示的“完成/未完成”状态为准。

## 功能

- 扫描原创帖子、引用、回复、转帖、点赞、关注和粉丝。
- 分别显示已读取数量，再选择清理类别与数量。
- 粉丝只统计，不执行移除。
- 取关只处理明确识别为“未回关”的账号；互关和关系未知账号会保留。
- 删除或取消后自动复扫，核对已处理项目是否仍存在。
- Cookie 仅保存在当前进程内，不写入文件。

## 安装与启动（macOS）

需要 Python 3.10 或更高版本。

双击 **启动.command**。首次运行会自动检查 Python、建立独立环境并安装依赖；以后直接进入程序。

也可以在终端运行：

```sh
chmod +x 启动.command
./启动.command
```

## 扫描与清理

流程固定为：

1. 输入浏览器中当前 X 会话的 `auth_token`（也可粘贴包含它的 Cookie 行）。输入默认不可见。
2. 程序携带 Cookie 请求 `https://x.com/home`，尝试补全 `ct0` 并读取绑定当前会话的用户名与 ID；网页仅返回 HTTP 200 不算登录成功。未获取到 `ct0` 时会请你手动输入。
3. 显示 X 返回的用户名，输入 yes 开始扫描；输入 no 重新输入 token。
4. 选择每页读取 50 或 100 项。程序继续翻页，直到接口没有下一页、发生限流/接口异常，或达到安全页数上限。
5. 查看原创、引用、回复、转帖、点赞、关注和粉丝的已读取数量。出现“未扫完”时，该数字不是账号总量。
6. 菜单：`1` 清理帖子，`2` 清理点赞，`3` 取关未回关账号；可输入 `1,3` 多选或输入 `all`。粉丝不在清理菜单中。
7. 输入各分类的清理数量；直接回车默认为 `0`。核对账号和数量后再次确认，程序才会执行不可撤销操作。
8. 完成后程序自动复扫。输入 `r` 可手动重新扫描，输入 `0` 退出。

重复分页游标不会丢弃已扫描结果；程序会保留已读取项目、继续其他分类，并明确提示扫描未完成。关系字段缺失时会补查粉丝列表；如果粉丝列表没有完整返回，对应账号保持“关系未知”，不会被取关。

## 常见报错

- **HTTP 401 / 登录会话失效**：重新登录 X，再获取新的 `auth_token` 和同一会话的 `ct0`。
- **HTTP 403 / X 拒绝请求**：在浏览器中完成账号验证，确认两个 Cookie 来自同一登录会话。
- **HTTP 404 / 网页接口已变化**：当前版本尚未适配 X 的最新接口，不要把部分扫描结果当作总量。
- **HTTP 429 / 已限流**：停止操作，稍后再试；程序不会自动重复提交写操作。
- **分页重复或达到安全上限**：已读取内容仍可显示，但扫描不完整。可稍后输入 `r` 重新扫描。
- **网络或代理失败**：确认 X 可访问，并检查 macOS 系统代理或手动代理地址。

## Cookie 安全

- 只用于管理你自己的账号。
- `auth_token` 和 `ct0` 等同登录凭证。不要截图、上传、提交到 Git 或发送给任何人。
- 程序使用隐藏输入，并在登录后清空内存中的原始输入；不会主动保存 Cookie。
- 不建议把 Cookie 放在命令行、环境变量、配置文件、日志或截图中。
- 使用后可退出 X 登录会话，使旧 Cookie 失效。

## 风险说明

- 删除和取消操作不可撤销。请先在 X 下载数据归档。
- 工具依赖 X 网页内部接口；X 改版、限流、验证或风控都可能让请求失败。
- `Articles` 长文章不在本工具的删除范围。
- 遇到不明确回执、限流或接口变化时会停止，不会盲目重试写操作。
- 使用者应自行遵守 X 的服务条款及所在地法律法规。作者不保证完整扫描、持续可用或适用于任何特定目的。

## 代理

程序会读取 macOS 当前启用的网页代理。也可在终端执行：

```sh
./.venv/bin/python cookie_cleaner.py --proxy http://127.0.0.1:7897
```

独立运行时可加 `--no-system-proxy` 禁用自动读取系统代理。
